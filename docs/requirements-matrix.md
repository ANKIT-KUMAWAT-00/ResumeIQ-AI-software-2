# Master prompt implementation matrix

| Requirement area | Included implementation | Notes / boundaries |
|---|---|---|
| Futuristic web UI | Next.js App Router, React, TypeScript, Tailwind, Framer Motion, responsive landing page and workspace | Frontend dependency build was not run in this offline environment; CI is configured to lint/build after package installation. |
| Authentication | Email OTP, expiry/attempt limits, hashed OTP, server-side hashed revocable sessions, HTTP-only cookies, origin guard, rate limiting | Production SMTP and domain/cookie setup must be configured. |
| Pricing and payments | Server-owned four-package catalog, Razorpay order creation, checkout signature verification, provider status fetch, captured webhook, idempotency, admin refund requests and refund status events | Requires Razorpay test credentials and webhook setup; no live transaction was run. |
| Resume ingestion | PDF/DOCX upload, size/signature checks, text extraction, optional OCR fallback, ownership checks | Scanned-PDF OCR needs Tesseract and Poppler; complex documents should be processed in isolated infrastructure. |
| Gemini analysis | Backend-only Google Gemini SDK, extraction and review passes, structured Pydantic schemas, bounded retries and one schema-repair pass, prompt versioning, nine role rubrics | No fabricated result if credentials are missing. Live API/quota behavior needs test credentials. |
| Review quality | Role-specific criteria, deterministic weighted role-fit score from rubric criterion scores, ATS findings, priority fixes, evidence-aware bullet rewrites and questions | Advisory heuristic, not a guaranteed ATS score, hiring probability, or employer decision. |
| Document templates | Validated TemplateSpec JSON, section field filtering/order, page geometry, margins, font family/sizes/colors, spacing, date tabs, bullets, rules, single/two-column layout, bounded fit-to-page adjustments | Photo placement is intentionally rejected by the current renderer. Content is never silently deleted. |
| Template analyzer | DOCX paragraph/OOXML/font/margin/tab inspection; PDF font/character geometry, line/rectangle inspection; JSON draft with uncertainty notes | An analyzer draft requires review. It does not claim exact reproduction from a flattened PDF. |
| LPU reference | The supplied PDF is included and used for the LPU Standard draft, including compact one-column structure, section order, heading style, two-column contact details, and right-aligned dates | The source is a completed resume, not an official blank LPU placement-cell specification. |
| Visual regression | Golden PNG baselines for all pages of all three templates; script compares pixel differences | Run `python scripts/visual_regression.py`; use `--update` only when intentionally accepting visual changes. Fonts and LibreOffice versions can affect output. |
| Background processing | RQ/Redis worker, persisted job status, retry endpoint, scheduled hourly retention cleanup service | Redis and shared private storage must be configured for multi-container deployment. |
| User data controls | Private local/S3-compatible storage, expiring signed S3 downloads, metadata/analysis export, deletion, configurable retention cleanup | Provider/backups retention must be handled by deployment policies too. |
| Admin console | Orders/revenue, refund requests, full-makeover queue, AI review JSON editing, revision status, template analyzer/editor/publish, persisted role-rubric editor, testimonial moderation with explicit consent, audit log API | Refunds and voice-note links depend on provider/external URLs. Human review is required before delivery. |
| Deployment and quality | Docker Compose, PostgreSQL, Redis, Alembic migrations, CI workflow, tests and operational docs | Docker image build and frontend build were not possible in this environment; run them before production. |
