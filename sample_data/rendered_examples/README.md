# Rendered sample outputs

These DOCX/PDF files were generated by the bundled renderer from `sample_data/reference_resume.json` using each checked-in template specification. They are included as quick examples, not as promises of identical pagination on every operating system. The LPU Standard output is inferred from `reference_resume.pdf`, not an official LPU template. Regenerate with `cd backend && python scripts/render_samples.py`.
